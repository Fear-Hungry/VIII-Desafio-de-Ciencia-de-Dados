# Dados históricos de ações (NYSE/NASDAQ) e Aprendizado por Reforço em Trading

## Fontes de dados históricos de preços de ações (NYSE e NASDAQ)

Para análises e modelagens de trading, existem diversas fontes públicas confiáveis de dados históricos de ações dos EUA (bolsas NYSE, NASDAQ), incluindo preços de **abertura**, **máxima**, **mínima**, **fechamento** e **volume** (OHLCV). Abaixo destacamos as principais fontes e seus detalhes:

- **Yahoo Finance** – Plataforma popular que fornece dados históricos diários de ações listadas nas bolsas americanas. É possível obter cotações completas (preço de abertura, alta, baixa, fechamento, volume e ajuste) de vários anos gratuitamente. Os dados podem ser acessados diretamente pelo site do Yahoo (com opção de download de CSV dos preços históricos) ([How to Download Historical Data from Yahoo Finance - Macroption](https://www.macroption.com/yahoo-finance-download-historical-data/#:~:text=Click%20Historical%20Data,if%20you%27ve%20made%20any%20changes)) ou via bibliotecas/API não-oficiais (por exemplo, a biblioteca Python `yfinance` utiliza a API do Yahoo). *Obs:* Até recentemente o download direto pelo site era aberto; atualmente algumas funcionalidades exigem login ou conta premium, mas os dados continuam acessíveis via API pública do Yahoo ([KB: Historical Prices from Google Finance to CSV](https://www.stock-data-solutions.com/kb/how-to-load-historical-prices-from-google-finance-to-csv.htm#:~:text=This%20article%20is%20archived,data%20via%20API%20in%202018)).

- **Nasdaq Data Link (Antes Quandl – WIKI EOD)** – A Quandl (agora Nasdaq Data Link) disponibilizava o conjunto *Wiki EOD Stock Prices*, um **dataset público** de fim de dia contendo preços diários (OHLC ajustado, volume) de ~3.000 ações americanas, incluindo também dividendos e splits ([WIKI Prices - Financial, Economic and Alternative Data](https://data.nasdaq.com/databases/WIKIP#:~:text=WIKI%20Prices%20,Data%20Specifications)). Esse dataset foi amplamente usado por ser de domínio público, porém foi **descontinuado em março de 2018** (não recebe mais atualizações) ([Why does Wiki Prices only go up to March 2018?](https://help.data.nasdaq.com/article/506-why-does-wiki-prices-only-go-up-to-march-2018#:~:text=Why%20does%20Wiki%20Prices%20only,going%20up%20to%20March%202018)). Ainda assim, os dados históricos até 2018 estão disponíveis gratuitamente via a plataforma Nasdaq Data Link ou através de repositórios como o Kaggle. Para dados mais recentes, o Nasdaq Data Link oferece outros feeds (alguns pagos) ou é possível recorrer a APIs gratuitas como as citadas aqui.

- **Alpha Vantage** – Serviço de API financeira gratuita que fornece **dados históricos** (e em tempo real) para ações, ETFs, moedas, etc. Com uma chave de API gratuita, é possível obter séries temporais diárias, semanais, mensais e intradiárias com mais de 20 anos de histórico de preços OHLCV ([API Documentation | Alpha Vantage](https://www.alphavantage.co/documentation/#:~:text=This%20API%20returns%20current%20and,adjusted%20intraday%20data%20from%20this)). Os dados vêm em formato JSON ou CSV via chamadas REST. Por exemplo, a API de “Time Series (Daily)” retorna, para um ticker dado, os preços de abertura, alta, baixa, fechamento e volume de cada dia. A Alpha Vantage é reconhecida como uma fonte confiável e amplamente usada por desenvolvedores e pesquisadores por oferecer acesso *gratuito* a dados acionários globais ([Free Stock APIs in JSON & Excel | Alpha Vantage](https://www.alphavantage.co/#:~:text=Stock%20Market%20Data%20APIs)) (dentro de limites de requisição diários).

- **Google Finance** – O Google Finance oferece dados históricos de ações através de sua interface web e integração com Google Sheets. É possível visualizar e coletar preços de abertura, máxima, mínima, fechamento e volume diários de ações listadas, usando por exemplo a função `GOOGLEFINANCE` em planilhas do Google para extrair cotações históricas. Um exemplo de dados obtido via Google Finance mostra colunas de **Date, Open, High, Low, Close, Volume** ([KB: Historical Prices from Google Finance to CSV](https://www.stock-data-solutions.com/kb/how-to-load-historical-prices-from-google-finance-to-csv.htm#:~:text=Date%2COpen%2CHigh%2CLow%2CClose%2CVolume%2019)). Contudo, o Google Finance **não disponibiliza uma API pública oficial** para download automatizado; a antiga API foi encerrada em 2018 ([KB: Historical Prices from Google Finance to CSV](https://www.stock-data-solutions.com/kb/how-to-load-historical-prices-from-google-finance-to-csv.htm#:~:text=This%20article%20is%20archived,data%20via%20API%20in%202018)). Ainda assim, os dados podem ser baixados manualmente do site (em CSV através da opção “Download to spreadsheet” na página de cada ativo, embora isso funcione apenas para períodos de ~1 ano por vez) ([KB: Historical Prices from Google Finance to CSV](https://www.stock-data-solutions.com/kb/how-to-load-historical-prices-from-google-finance-to-csv.htm#:~:text=You%20can%20use%20URLs%20like,pages%20with%20historical%20prices%20directly)) ou coletados via planilhas conforme mencionado.

- **Kaggle e outras fontes comunitárias** – Além das fontes oficiais acima, a comunidade frequentemente compila e compartilha datasets históricos. Por exemplo, o Kaggle hospeda conjuntos de dados contendo preços diários de todas as ações da NASDAQ ([Stock Market Dataset - Kaggle](https://www.kaggle.com/datasets/jacksoncrow/stock-market-dataset/data#:~:text=Stock%20Market%20Dataset%20,com)) ou da NYSE ([NYSE daily stock prices - Kaggle](https://www.kaggle.com/datasets/svaningelgem/nyse-daily-stock-prices#:~:text=NYSE%20daily%20stock%20prices%20,stock%20exchange%20by%20market%20capitalization)) ao longo de décadas. Esses datasets geralmente são derivados de fontes como Yahoo Finance ou APIs gratuitas, oferecendo conveniência de já terem todos os tickers agregados em arquivos únicos. Embora não sejam “fontes primárias” oficiais, podem ser úteis para acesso rápido a dados históricos consolidado. É recomendável sempre verificar a origem e atualidade desses datasets (por exemplo, se estão atualizados até o presente ou até determinada data).

## Trabalhos aplicados de Aprendizado por Reforço para negociação de ações

Nos últimos anos, diversos **estudos aplicados** demonstraram o uso de **aprendizado por reforço profundo (DRL)** para otimizar estratégias de negociação de ações visando maximizar lucros. Abaixo resumimos alguns trabalhos recentes e bem-citados que implementam agentes de RL em cenários de trading realistas (usando frameworks em Python como TensorFlow, PyTorch/Stable-Baselines) e validam os resultados com dados históricos do mercado americano:

- **Liu et al. (2018)** – *“Practical Deep Reinforcement Learning Approach for Stock Trading”*. Este estudo (Workshop NeurIPS 2018) explorou o uso de DRL para definir estratégias ótimas de trading no mercado de ações. Os autores modelaram o problema como um MDP e aplicaram o algoritmo **Deep Deterministic Policy Gradient (DDPG)** para treinar um agente em dados diários das ações do índice Dow Jones (30 empresas dos EUA). O desempenho do agente treinado foi comparado tanto ao índice Dow Jones Industrial Average (DJIA) quanto a uma estratégia tradicional de alocação ótima (mínima variância). O resultado mostrou que a abordagem com **RL superou ambas as baseline** – obtendo retorno cumulativo e índice de Sharpe maiores que os do DJIA e da carteira de mínima variância ([[1811.07522] Practical Deep Reinforcement Learning Approach for Stock Trading](https://ar5iv.org/abs/1811.07522#:~:text=stock%20trading%20strategy%20and%20thus,Sharpe%20ratio%20and%20cumulative%20returns)). Isso evidenciou o potencial do aprendizado por reforço em captar a dinâmica complexa do mercado melhor que métodos convencionais.

- **Yang et al. (2020)** – *“Deep Reinforcement Learning for Automated Stock Trading: An Ensemble Strategy”*. Trabalho apresentado na ACM ICAIF 2020, propôs uma estratégia de trading baseada em um **ensemble de algoritmos de RL profundo**. Três métodos actor-critic diferentes – **Proximal Policy Optimization (PPO)**, **Advantage Actor-Critic (A2C)** e **Deep Deterministic Policy Gradient (DDPG)** – foram treinados como agentes que aprendem a operar um conjunto de ações (também testado sobre as 30 ações do Dow Jones). A estratégia conjunto combina os três agentes para aproveitar as melhores características de cada algoritmo em diferentes condições de mercado. Os testes mostraram que o **método de ensemble superou não só cada agente individual, mas também benchmarks** como o próprio índice Dow Jones e a estratégia de mínima variância, obtendo **retornos ajustados ao risco (Sharpe ratio) superiores** aos benchmarks ([Deep Reinforcement Learning for Automated Stock Trading: An Ensemble Strategy](https://openfin.engineering.columbia.edu/sites/default/files/content/publications/ensemble.pdf#:~:text=space%2C%20we%20employ%20a%20load,adjusted%20return)). Em suma, integrar múltiplos algoritmos de RL tornou a estratégia mais robusta a diferentes regimes de mercado. (Os autores disponibilizaram o código deste trabalho; ele foi implementado em Python utilizando frameworks de deep learning e integra-se ao projeto open-source **FinRL**.)

- **Zou et al. (2024)** – *“A novel Deep Reinforcement Learning based automated stock trading system using cascaded LSTM networks”*. Este estudo muito recente (publicado no *Expert Systems with Applications* em 2024) aborda os desafios de se aplicar RL em dados financeiros ruidosos. Os autores propõem um modelo chamado **CLSTM-PPO**, que combina redes neurais LSTM em cascata com o algoritmo PPO. Essencialmente, uma LSTM inicial extrai padrões temporais dos dados diários de ações, e outra LSTM é incorporada na arquitetura actor-critic do PPO para capturar dependências de longo prazo nas decisões do agente. O sistema foi avaliado em dados históricos de quatro mercados, incluindo um dos EUA (o índice Dow Jones – DJI), além de índices da China (SSE50), Índia (Sensex) e Reino Unido (FTSE100). Comparado a diversas estratégias de referência – desde *buy-and-hold* até modelos baseados em redes neurais tradicionais e um modelo ensemble anterior – o **CLSTM-PPO apresentou desempenho superior** em métricas como retorno cumulativo, taxa máxima de ganho e lucro médio por trade, com melhorias que variaram de **5% a 52%** sobre os benchmarks dependendo do índice avaliado ([A novel Deep Reinforcement Learning based automated stock trading system using cascaded LSTM networks | OpenReview](https://openreview.net/forum?id=Cg62XWArYf&referrer=%5Bthe%20profile%20of%20Baohua%20Wang%5D(%2Fprofile%3Fid%3D~Baohua_Wang1)#:~:text=based%20on%20a%20buy,an%20automated%20stock%20trading%20system)). Os resultados indicam que incorporar estruturas de memória (LSTM) pode aprimorar a capacidade do RL em extrair sinais de séries temporais financeiras, resultando em estratégias mais lucrativas.

- **Ge et al. (2022)** – *“Single stock trading with deep reinforcement learning: A comparative study”*. Este trabalho (proceedings ACM, 2022) realizou uma **análise comparativa** de múltiplos algoritmos de DRL aplicados à negociação de um único ativo. Os autores implementaram e compararam cinco métodos: **A2C, PPO, DDPG, TD3 e SAC** (Soft Actor-Critic). Em seus experimentos, eles usaram dados históricos de um ativo (no caso, testaram com uma ação de mercado asiático) divididos em período de treino e teste (pré e pós a crise do COVID-19) para avaliar a generalização. Os resultados mostraram diferenças marcantes entre algoritmos: os agentes **DDPG, TD3 e SAC superaram claramente o benchmark de mercado**, com o DDPG obtendo o melhor desempenho (e.g. ~25% de retorno cumulativo no teste, superando os demais também em controle de risco), enquanto os métodos mais simples **A2C e PPO tiveram desempenho inferior ao benchmark** do mercado ([Single stock trading with deep reinforcement learning: A comparative study | CoLab](https://colab.ws/articles/10.1145%2F3529836.3529857#:~:text=In%20this%20paper%2C%20we%20apply,A2C%20and%20PPO%20models%20have)). Ou seja, algoritmos off-policy mais avançados conseguiram capturar melhores estratégias de trade que os on-policy mais simples nesse cenário. Este estudo destaca a importância de selecionar algoritmos de RL adequados e demonstra que abordagens mais sofisticadas tendem a melhor rentabilidade em trading de ações individuais.

- **Pigorsch & Schäfer (2021)** – *“High-Dimensional Stock Portfolio Trading with Deep Reinforcement Learning”*. Diferente dos anteriores focados em poucos ativos ou single-stock, este trabalho (arXiv preprint, 2021) explora RL para **negociar carteiras de alta dimensão**. Os autores propuseram um algoritmo baseado em **Deep Q-Learning** capaz de lidar com portfólios de dezenas ou centenas de ações simultaneamente. A técnica envolveu treinar o agente em múltiplos ambientes, cada um correspondendo a um ativo amostrado, recompensando o agente de acordo com o retorno relativo de cada ativo (forçando o agente a alocar capital nos ativos com desempenho acima da média). Em testes com **portfólios de ações dos EUA** (variando de 10 até 500 ações escolhidas de diferentes formas, incluindo S&P 500 completo) o agente treinado conseguiu **superar por larga margem estratégias benchmarks passivas (como índices) e ativas** tradicionais em todos os cenários avaliados ([[2112.04755] High-Dimensional Stock Portfolio Trading with Deep Reinforcement Learning](https://arxiv.org/abs/2112.04755#:~:text=reservation%20with%20the%20average%20return,hyperparameter%20setup%20for%20all%20portfolios)). Notavelmente, um único conjunto de hiperparâmetros de RL funcionou bem para portfólios de tamanhos variados, sugerindo robustez da abordagem. Este estudo reforça que métodos de RL podem escalar para cenários de portfólio amplo e ainda assim obter vantagem de performance sobre estratégias convencionais.

**Nota sobre implementação:** Muitos desses trabalhos disponibilizaram seus *frameworks* e código, geralmente construídos em Python com bibliotecas de deep learning. Por exemplo, os desenvolvedores dos estudos de 2018–2020 acima lançaram o **FinRL**, um framework aberto de aprendizado por reforço para finanças quantitativas, com implementações de algoritmos como DDPG, PPO, SAC etc., utilizando Keras/TensorFlow nas versões iniciais e atualmente PyTorch com Stable-Baselines3 ([GitHub - AI4Finance-Foundation/FinRL: FinRL®:  Financial Reinforcement Learning. ](https://github.com/AI4Finance-Foundation/FinRL#:~:text=FinRL%3A%20A%20deep%20reinforcement%20learning,RL%20Workshop%20paper%2087%202020)). A disponibilidade de tais frameworks tem facilitado a reprodução das estratégias apresentadas nesses artigos e servido de base para novos desenvolvimentos na aplicação de RL ao mercado acionário.
